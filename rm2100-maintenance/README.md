# RM2100 阶段备份

此目录保存已验证阶段的源码差异和测试摘要。它不是 U9/U10 的完整、独立可编译源码树；仓库根目录仍是原有远程版本，不能把根目录当前的编译结果当成本次固件。

## 内容与顺序

- `patches/001-U8r3-to-U9-source.patch`：本地 U8r3 基线到 U9 的差异，包括构建基础修复、DDNS-Go 和 IPTV 适配。
- `patches/002-U9-to-U10-optional-plugins.patch`：U9 到 U10 的可选组件适配差异。
- `docs/validation-status.json`：校验值、验收范围及仍在进行的工作。

这两组补丁以本地 U8r3/U9 的对应源码为前提，不能直接套用到上游原版或本分支根目录。此前内核、工具链、无线驱动和其他修复尚待按可复现的顺序整合；透明代理及剩余插件测试结束后再整合完整源码。

## 已验证范围

U9 与 U10 均做过整机启动和基本网络检查，用户分别确认过两路 Wi-Fi 能上网。日常设备已恢复 U9。

Sing-box 1.14.4 与 Mihomo 1.19.33 已在真实 RM2100 运行官方 MIPS 程序，通过临时节点验证 VLESS、VMess、Trojan、Shadowsocks 的 TCP、HTTPS、上传和并发；前三种还验证了 UDP。两核心另经 VLESS、Trojan 访问公共 HTTPS 网站。此次未安装为长期常驻服务。

FRP、ZeroTier、SmartDNS、aria2、Transmission、Samba 等已完成各自记录范围内的交叉编译和虚拟环境功能测试。虚拟机测试不能替代其他机型、真实 USB/硬盘、运营商 IPTV、真实 DDNS 服务商或持续运行验收。
