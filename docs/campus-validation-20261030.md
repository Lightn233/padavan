# 校园组件修复与工具链构建验证（2026-10-30）

本批已整合进维护源码；没有将校园网组件默认加入 RM2100 日常配置。保留 `make RM2100` 及其他机型的配置选择方式。

## 已修复

| 组件 | 修复内容 |
| --- | --- |
| MiniEAP | RJv3 属性和帧长度、复制容量、未对齐访问、分配失败及字符转换错误处理 |
| GDUT-DRCOM | 配置长度、数值和地址校验；错误时保留原配置；日志边界、CRC 对齐及回复来源检查 |
| MentoHUST | 捕获长度和消息范围、请求头生命周期、MD5 输入容量、账户输入上限与终端回显恢复；配置字符原样写入、失败保留旧配置 |
| Dogcom | 空行及无效配置、字段长度、修改版心跳标记、校验值缓冲区、心跳报文长度及奇数密码填充 |
| SCUTClient | MD5 输入、十六进制和命令行参数、未对齐 CRC、报文及消息长度；可选启动参数不再传成空字符串 |

MentoHUST 与 SCUT 的启动入口改为互斥操作，不再直接按遗留 PID 文件执行强制终止；真实启动失败返回非零状态。

## U12 补充验收

2026-10-30 已在 Ubuntu 隔离网络中验证正常 TAP 认证检查器，然后在 RM2100 的 U11、U12 内核上原生运行同一个已编译 MIPS MentoHUST 组件及 libpcap。临时 TAP 不连接物理网口或 br0；私有挂载命名空间隔离配置与 PID 文件。

两轮身份与 MD5 响应、认证成功心跳、重新认证和正常退出均通过；每轮结束后进程、TAP、临时文件全部移除，真实 NVRAM 和 AdGuardHome 程序及配置未改变。这补上了真实 MIPS 内核的 libpcap 正常收发路径，仍不代表真实校园账号、物理校园接入网卡或全部学校私有扩展已验收。原 QEMU 用户态接口限制如实保留，不把模拟器限制当作已修复的产品缺陷。

正常协议检查器保存在 `tests/campus/mentohust_tap_check.c`。本批源码整合、完整固件和实机基础检查见 [U12 整合记录](maintenance-2026-10-30-u12.md)。校园组件默认关闭，完整日常固件编译本身不替代这些组件测试。
